# Seismic Solidity Releases

This repository hosts the binaries for Seismic Solidity, Seismic's customized fork of the Solidity compiler.

## Included Binaries

- macOS (x86_64, arm64)
- Linux (x86_64, arm64)

## Usage

Visit the [Releases](https://github.com/SeismicSystems/seismic-solidity-releases/releases) section to download the binaries.
